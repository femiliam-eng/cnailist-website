# 💅 Cnailist - Nail Art Booking & E-Commerce Website

## 📖 Deskripsi Project

Cnailist merupakan website layanan nail art yang dirancang untuk memudahkan pelanggan dalam melihat katalog desain kuku, melakukan pemesanan, membuat permintaan desain khusus (custom order), serta memantau status pesanan. Website ini juga menyediakan dashboard admin untuk mengelola produk, pesanan, pelanggan, dan komunikasi dengan pelanggan.

Project ini dikembangkan sebagai bagian dari pembelajaran dan implementasi pengembangan aplikasi web.

---

## ✨ Fitur Utama

### 👩‍💼 Fitur Pelanggan

* Beranda (Home Page)
* Melihat katalog nail art
* Melihat detail produk
* Menambahkan produk ke keranjang (Cart)
* Melakukan pemesanan custom nail art
* Melacak status pesanan (Order Tracking)
* Sistem autentikasi pengguna

### 👩‍💻 Fitur Admin

* Login Admin
* Dashboard Admin
* Manajemen Produk
* Manajemen Pesanan
* Manajemen Data Pelanggan
* Fitur Chat dengan pelanggan
* Sistem notifikasi admin

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/username/cnailist.git
```

### 2. Masuk ke Folder Project

```bash
cd cnailist
```

### 3. Setup Backend

Masuk ke folder backend:

```bash
cd cnailist-backend
```

Install dependencies:

```bash
npm install
```

### 4. Konfigurasi Database

* Buat database MySQL baru.
* Import file:

```text
database.sql
```

* Atur konfigurasi database pada file `.env`.

### 5. Jalankan Backend

```bash
npm start
```

atau

```bash
node server.js
```

### 6. Jalankan Frontend

Buka file `index.html` menggunakan browser atau jalankan menggunakan extension **Live Server** pada Visual Studio Code.
